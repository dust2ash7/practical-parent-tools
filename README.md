# Parent Tools

A small website with calculators and guides:

- Baby wake windows and a sample sleep day
- Diaper size by weight and monthly cost
- Sleep schedule by age
- How many diapers per month by age
- EV vs hybrid driving cost, with Southern California electricity and gas defaults

Estimates and general guidelines only. Not medical, utility, or purchase advice.

## Develop

```bash
npm install
npm run dev
```

The dev server listens on port 8080.
